# Free Open-Source Website & Landing Page Resources for Beyond Pixells (Gym OS)

## Overview & Studio Context
**Beyond Pixells** is a solo-founder product studio based in India building **Gym OS** (gym management software). 
- **Tech Stack**: Static landing pages hosted on **GitHub Pages**, backed by **Base44** serverless endpoints.
- **Design System**: Dark canvas (#09090B / #0D0D12), **crimson-amber gradient accents** (`from-rose-600 via-crimson-500 to-amber-500`), and bold **Space Grotesk** typography.
- **Goal**: Maximize landing page conversion, design aesthetic, and feature showcase while keeping zero-maintenance static hosting on GitHub Pages and minimizing solo-founder overhead.

Below is a curated, ranked selection of **13 top active, free open-source repositories** organized across animation, components, asset sources, form backends, and AI/OG image generation.

---

## 1. shadcn/ui
- **Repository / URL**: [https://github.com/shadcn-ui/ui](https://github.com/shadcn-ui/ui)
- **Category**: Component Libraries / Templates
- **What It Does**: Accessible, composable React component code built with Tailwind CSS and Radix UI that developers copy and paste directly into their codebase.
- **Why It Helps Beyond Pixells**: Provides complete code ownership with zero external CSS dependencies. Easily themeable via CSS variables to match Gym OS's dark canvas background, crimson-amber focus rings, and Space Grotesk font hierarchy across all static pages on GitHub Pages.
- **GitHub Stars & Activity**: **124,600+ stars** | Active (pushed September 2026).
- **License / Pricing**: **100% Free** | MIT License.

## Summary Stack Blueprint for Gym OS Landing Pages
| Component Layer | Recommended Tool | Integration Method on GitHub Pages |
| :--- | :--- | :--- |
| **Core UI Components** | `shadcn/ui` + `HeroUI` | Build static bundle via Next.js/Vite, styled with crimson-amber CSS variables + Space Grotesk. |
| **Landing Animations** | `Magic UI` + `Atropos` + `Lenis` | Copy-paste React components for glowing CTAs, smooth scrolling, and 3D card tilt. |
| **Background & Accents** | `Background Snippets` + `tsParticles` | Tailwind ambient dark grid & crimson/amber particle embers. |
| **Icons & Media** | `Lucide Icons` | SVG icons embedded into static pages. |
| **Form Backend & Leads** | `Formizee` / `Formbricks` | Static HTML/React forms submitting to Base44 webhooks or Formizee API. |
| **Social / OG Images** | `Takumi` / `Satori` + `Shot-Scraper` | Automated build-time generation of dark crimson OG cards and automated dashboard screenshots. |
