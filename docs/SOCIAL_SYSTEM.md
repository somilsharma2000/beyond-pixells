# Beyond Pixells — Social Content System

> Full spec: `research/social_system.md`. The idea: **all social content is
> generated FROM the web design language** — same tokens, fonts, gradient — so
> every reel looks like our sites in motion.

## Working templates (screen-record these at 100% browser zoom)
- `assets/social-templates/stat-drop.html` — Format 1: giant animated stat on dark canvas
- `assets/social-templates/hook-card.html` — Format 3: one bold hook, kinetic gradient text

Open in browser → edit the 3 EDIT-ME lines → screen-record 3–5s → export 1080×1920 reel.

## The 10 formats (from research)
1. **Stat Drop** — big number + claim (loss-aversion hooks)
2. **UI Demo Reel** — screen recording of the live platform with kinetic captions
3. **Hook Card** — one line, gradient highlight ("The gym across the street...")
4. **Churn Radar** — at-risk member alert visualization
5. **Before/After** — register chaos → Gym OS dashboard
6. **Micro-Feature** — one feature, 5s ("QR check-in in 2 seconds")
7. **Feature Matrix** — us vs them table as a card
8. **Kinetic Quote** — owner/industry quote animated
9. **Process 1-2-3** — "register → WhatsApp → dashboard"
10. **Build Log** — studio proof, what we shipped this week

## Pipeline (1–2 person team)
Batch: record 5 templates in one sitting → cut in CapCut → captions → schedule.
Cadence: 4 reels/week per product line (2 Gym OS, 1 studio, 1 rotating product).

## Product → format matrix
- **Gym OS**: Stat Drop, Before/After, UI Demo, Hook Card, Churn Radar
- **Dentist OS**: Stat Drop (no-show %), Process 1-2-3, Micro-Feature (recall automation)
- **Studio brand**: Build Log, Feature Matrix, Kinetic Quote
