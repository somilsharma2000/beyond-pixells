## The Playbooks

- **Brand**: positioning is locked in `docs/BRAND_PLAYBOOK.md` — "operating
  systems for local businesses", endorsed-hybrid architecture, the `__ OS` family.
- **Business**: `docs/BUSINESS_PLAYBOOK.md` — services cashflow → products scale,
  flat-INR pricing, the vertical launch playbook, survival rules and metrics.
- **Research**: every major decision traces to a report in `docs/research/`.
